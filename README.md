# Poca Lens

Initial React Native mobile application foundation built with Expo and TypeScript.

## Getting started

```bash
npm install
npm run start
```

Then use Expo Go or an emulator to open the app.

## Project structure

```text
App.tsx                 # Root app component and providers
src/components/         # Reusable UI components
src/screens/            # Screen-level React Native views
src/theme/              # Design tokens for colors, spacing, radius, typography
src/types/              # Shared TypeScript types
assets/                 # Static app assets
```

## Available scripts

- `npm run start` - start the Expo development server.
- `npm run android` - start Expo and open Android target.
- `npm run ios` - start Expo and open iOS target.
- `npm run web` - start Expo for web.
- `npm run typecheck` - run TypeScript validation.
